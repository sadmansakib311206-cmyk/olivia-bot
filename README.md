# Messenger Page Bot — অলিভিয়া, ফেসবুক পেজের AI বন্ধু

তোমার ফেসবুক পেজের বটের নাম **অলিভিয়া (Olivia)** — বন্ধুত্বপূর্ণ মেয়ে চরিত্র। পেজে যারা মেসেজ করবে, অলিভিয়া তাদের সঙ্গে বন্ধুর মতো স্বাভাবিকভাবে আড্ডা দেবে, আগের কথা মনে রেখে। যেকোনো ভাষায় মেসেজ করলে সেই ভাষাতেই উত্তর দেবে (বাংলা, ইংরেজি, হিন্দি, উর্দু, আরবি, ইন্দোনেশিয়ান, স্প্যানিশ, ফরাসি, চাইনিজ, রাশিয়ান...) — ভাষা চিনতে না পারলে ইংরেজিতে। পেজের নিজের পোস্ট ইংরেজিতে (মজার পোস্ট/মিম)। উত্তর বানায় Gemini (তোমার নিজের ফ্রি key)। অলিভিয়ার ছবি: `media-generation-olivia-avatar-0-d33eeb9d-a9ec-44f6-af6d-30272058c635.webp` (পেজের প্রোফাইল ছবি হিসেবে ব্যবহার করা যাবে)।

**সবচেয়ে গুরুত্বপূর্ণ সীমা:** অলিভিয়া কখনো নিজেকে আসল মানুষ বলে পরিচয় দেবে না। কেউ "তুমি কি মানুষ?" জিজ্ঞেস করলে — যেকোনো ভাষায় জিজ্ঞেস করলেও — সরাসরি সেই ভাষাতেই বলবে সে পেজের AI বন্ধু। ভুয়া বয়স/পেশা/জীবনকাহিনি নেই। বন্ধুত্বপূর্ণ আড্ডা হ্যাঁ, মানুষ সাজা না।

## ফাইলগুলো

| ফাইল | কাজ |
|---|---|
| `server.js` | Webhook সার্ভার — Meta যাচাই (GET), মেসেজ গ্রহণ (POST), Gemini উত্তর, Graph API-তে পাঠানো, অটো পোস্ট শিডিউলার + `/post-now`, কমেন্টের উত্তর |
| `package.json` | Node ডিপেন্ডেন্সি (express, dotenv) |
| `.env.example` | কী কী গোপন মান (env var) লাগবে — আসল `.env` তুমি নিজে বানাবে |
| `test-local.js` | Meta ছাড়াই লোকাল টেস্ট — মেসেজ, পরিচয়-উত্তর, বহুভাষিক উত্তর |
| `test-posts.js` | অটো পোস্ট + কমেন্ট উত্তরের লোকাল টেস্ট (শিডিউলারসহ, ~২ মিনিট) |
| `memory.json` | প্রতি sender-এর শেষ ১০ আদান-প্রদান (অটো তৈরি হয়) |
| `outbox.json` | TEST_MODE-এ পাঠানো মেসেজ/পোস্ট/কমেন্ট-উত্তরের লগ (টেস্টে তৈরি হয়) |
| `posts.json` | প্রকাশিত পোস্টের হিসাব — কোন স্লটে কী পোস্ট হয়েছে, আগের পোস্টের লেখা (অটো তৈরি হয়) |
| `comment-replies.json` | কোন কমেন্ট-থ্রেডে উত্তর দেওয়া হয়েছে তার হিসাব (অটো তৈরি হয়) |
| `media-generation-olivia-avatar-*.webp` | অলিভিয়ার ছবি — পেজের প্রোফাইল ছবি হিসেবে ব্যবহার করা যাবে |

## ১) লোকালে চালানো

```bash
cd messenger-page-bot
npm install
cp .env.example .env
# .env খুলে এগুলো বসাও:
#   VERIFY_TOKEN=তোমার-গোপন-টোকেন
#   GEMINI_API_KEY=তোমার-ফ্রি-Gemini-key
#   PAGE_ACCESS_TOKEN= (লোকাল টেস্টে লাগে না)
#   TEST_MODE=1  (লোকাল টেস্টে 1 রাখো)
npm start
```

সার্ভার চলবে `http://localhost:3000`-এ।

**টেস্ট (Meta ছাড়াই):**

```bash
node test-local.js
```

এটা নিজে সার্ভার চালিয়ে webhook যাচাই, বাংলা মেসেজ, "are you human?" / "তুমি কি মানুষ?" প্রশ্নের সৎ উত্তর, ছবির উত্তর, typing indicator — আর বহুভাষিক উত্তর (বাংলা, ইংরেজি, হিন্দি, ইন্দোনেশিয়ান মেসেজে সেই ভাষাতেই উত্তর; হিন্দি/ইন্দোনেশিয়ানে পরিচয়-প্রশ্নের সৎ উত্তর) — সব পরীক্ষা করে। ১৬/১৬ পাস হওয়া উচিত। `GEMINI_API_KEY` না থাকলে উত্তরগুলো fallback হবে (পরিচয়-উত্তর আর ছবির উত্তর এমনিতেই আসল)।

**অটো পোস্ট + কমেন্টের টেস্ট:**

```bash
node test-posts.js
```

এটা পরীক্ষা করে: key ছাড়া `/post-now` পোস্ট করে না (কারণসহ ফেরত), টোকেন ছাড়া `/post-now` 403 দেয়, stub Gemini দিয়ে পোস্ট হয়, একই পোস্ট দুবার হয় না, সাধারণ কমেন্টে উত্তর আসে, এক থ্রেডে ২য় উত্তর নয়, স্প্যাম/গালি-কমেন্টে উত্তর নয়, পেজের নিজের কমেন্টে উত্তর নয়, কমেন্টে পরিচয়-প্রশ্নের সৎ উত্তর, আর শিডিউলার সময়মতো পোস্ট করে। মোট ২২টি চেক, ~২ মিনিট লাগে (শিডিউলার পরীক্ষায় ~৮০ সেকেন্ড অপেক্ষা আছে)। দুটো একসাথে চালাতে: `npm test`।

## ২) Meta developer app বানানো

১. [developers.facebook.com](https://developers.facebook.com)-এ যাও → **My Apps** → **Create App** (ধরন: Business)।
২. App-এ **Messenger** প্রোডাক্ট যোগ করো।
৩. Messenger সেটিংসে তোমার **Page connect** করো (তুমি ওই পেজের Admin হতে হবে)।
৪. **Page Access Token** নাও — permission: `pages_messaging` (মেসেজের উত্তর), `pages_manage_posts` (অটো পোস্ট), `pages_manage_engagement` + `pages_read_engagement` (কমেন্টের উত্তর)। টোকেনটা শুধু `.env`-এ (বা Render-এর Environment Variables-এ) বসাবে — **কখনো কাউকে দেবে না, কোডে বসাবে না, GitHub-এ তুলবে না**। নতুন পারমিশনগুলোর (পোস্ট/কমেন্ট) জন্য Meta-র app review লাগতে পারে — লাইভে যাওয়ার আগে অ্যাপের Permissions অংশে দেখে নিও।

## ৩) Webhook বসানো ও subscribe করা

Messenger সেটিংসের **Webhooks** অংশে:

- **Callback URL:** `https://তোমার-সার্ভার/webhook` (যেমন `https://messenger-page-bot.onrender.com/webhook`)
- **Verify Token:** `.env`-এর `VERIFY_TOKEN`-এর মান (দুটো হুবহু এক হতে হবে)
- **Verify and Save** চাপো — সার্ভার ঠিক থাকলে সবুজ টিক আসবে।
- তারপর **Subscribe** করো: `messages` আর `messaging_postbacks` (দুটোতেই টিক দাও)।
- **কমেন্টের উত্তরের জন্য** একই Webhooks অংশে **Page** সাবস্ক্রিপশনে `feed`-এও টিক দাও — পেজের পোস্টে কেউ কমেন্ট করলে Meta তখন সার্ভারে `feed` ইভেন্ট পাঠাবে, অলিভিয়া প্রসঙ্গ বুঝে মজার উত্তর দেবে।

এরপর পেজে কেউ মেসেজ করলেই Meta তোমার সার্ভারে পাঠাবে, অলিভিয়া typing দেখিয়ে উত্তর দেবে।

## ৩ক) অটো পোস্ট আর কমেন্টের উত্তর

**অটো পোস্ট:** অলিভিয়া নিজে মজার ইংরেজি পোস্ট লিখবে (ছোট কৌতুক, এক লাইনের মজা, দৈনন্দিন রিলেটেবল হাসির কথা — হালকা, সবার জন্য উপযুক্ত, কাউকে আঘাত করে এমন মজা নয়) আর Graph API দিয়ে পেজে পাবলিশ করবে। আপাতত টেক্সট-পোস্ট (ছবিসহ মিম পরে)।

- ফ্রিকোয়েন্সি `.env`-এ: `POSTS_PER_DAY=5`, `POST_TIMES=08:00,11:00,14:00,17:00,20:00` (ঢাকা সময় — সকাল, বেলা, দুপুর, বিকেল, রাত)। সময় বদলাতে চাইলে `POST_TIMES`-এর মান বদলাও। `POST_ENABLED=0` করলে শিডিউলার বন্ধ থাকবে।
- সার্ভারে in-process শিডিউলার আছে (প্রতি মিনিটে চেক করে)।

**⚠️ Render ফ্রি টিয়ারের ঘুম-সীমা (সৎ কথা):** ফ্রি সার্ভার ১৫ মিনিট অলস থাকলে ঘুমিয়ে যায়। ঘুমন্ত সার্ভারে in-process শিডিউলার চলবে না — তাই শুধু শিডিউলারের ভরসায় নিয়মিত পোস্ট হবে না। নিয়মিত পোস্ট চাইলে দুটো উপায়:
  1. **বাইরের ফ্রি cron (সহজ, ফ্রি):** [cron-job.org](https://cron-job.org)-এ ফ্রি অ্যাকাউন্ট খুলে Create cronjob করো — URL: `https://তোমার-সার্ভার.onrender.com/post-now?token=তোমার-POST_NOW_TOKEN`, Method: POST, সময়: প্রতিদিন ০৮:০০, ১৩:০০, ১৯:০০ (Asia/Dhaka)। cron ডাকলেই সার্ভার জেগে উঠবে আর পোস্ট করবে। `POST_NOW_TOKEN` `.env`-এ বসাতে ভুলো না (না বসালে `/post-now` খোলা থাকবে — যেকেউ পোস্ট করাতে পারবে, তাই টোকেন বসানোই ভালো)।
  2. **পেইড ইনস্ট্যান্স:** Render-এর $৭/মাসের প্ল্যানে সার্ভার ঘুমায় না — তখন in-process শিডিউলারই যথেষ্ট।

**হাতে পোস্ট করানো:** `POST /post-now` ডাকলেই তখনই একটা পোস্ট হবে (টোকেন থাকলে `?token=...` দিতে হবে)।

**কমেন্টের উত্তর:** পেজের পোস্টে কেউ কমেন্ট করলে অলিভিয়া প্রসঙ্গ বুঝে মজার উত্তর দেবে (১–২ বাক্য, কমেন্টের ভাষাতেই)। নিয়ম:
- প্রতি কমেন্ট-থ্রেডে সর্বোচ্চ **১টি** উত্তর — একই থ্রেডে বারবার উত্তর দিয়ে স্প্যাম করবে না।
- স্প্যাম/গালি/ঘৃণামূলক কমেন্টে (লিংক, ইনবক্সে ডাকা, টাকা ইনকামের প্রলোভন, গালি) উত্তর দেবে না — এড়িয়ে যাবে।
- `GEMINI_API_KEY` না থাকলে পোস্টও বানাবে না, কমেন্টের উত্তরও দেবে না — লগে স্পষ্ট লেখা থাকবে, ভুয়া পোস্ট/উত্তর বানাবে না।

## ৪) ফ্রি হোস্টিং — Render (ফ্রি টিয়ার, ২২ নভেম্বর ২০২৬-এ যাচাই করা)

১. কোডটা GitHub-এ push করো (`.env` কখনো push করবে না — `.gitignore`-এ আছে)।
২. [render.com](https://render.com)-এ ফ্রি অ্যাকাউন্ট খুলে **New → Web Service** → GitHub repo connect করো।
৩. **Build Command:** `npm install` · **Start Command:** `npm start` · **Plan: Free** (কার্ড লাগে না)।
৪. **Environment Variables**-এ বসাও: `VERIFY_TOKEN`, `PAGE_ACCESS_TOKEN`, `GEMINI_API_KEY` (আর চাইলে `APP_SECRET`)। `TEST_MODE` বসাবে না (বা `0`)।
৫. Deploy হলে Render একটা `https://...onrender.com` লিংক দেবে — ওটাই ধাপ ৩-এর Callback URL (`/webhook` যোগ করে)।

**ফ্রি টিয়ারের সীমা (জেনে রাখো):**
- ১৫ মিনিট মেসেজ না এলে সার্ভার ঘুমিয়ে যায়; পরের মেসেজে জাগতে ~১ মিনিট লাগে (প্রথম উত্তর দেরিতে আসতে পারে)।
- ফ্রি সার্ভারে ফাইলপদ্ধতি অস্থায়ী — ঘুম থেকে জাগলে/রিস্টার্টে **`memory.json` মুছে যায়, বট আগের কথা ভুলে যায়**। স্মৃতি স্থায়ী রাখতে পরে ছোট ডাটাবেস (যেমন Render Key Value/ফ্রি Postgres) লাগবে।
- মাসে ৭৫০ ফ্রি ঘণ্টা — একটা সার্ভিসের জন্য যথেষ্ট।

- করে: টেক্সট মেসেজে বন্ধুর মতো আড্ডা (যেকোনো ভাষায় — মেসেজের ভাষাতেই উত্তর), আগের ১০ আদান-প্রদান মনে রাখা, প্রথম মেসেজে শুভেচ্ছা ("হাই! আমি অলিভিয়া..."), উত্তরের আগে typing দেখানো, "তুমি কি মানুষ?"-এ যেকোনো ভাষায় সৎ উত্তর; দিনে ৫টি মজার ইংরেজি পোস্ট (০৮:০০/১১:০০/১৪:০০/১৭:০০/২০:০০, ঢাকা সময়); কমেন্টে প্রসঙ্গ বুঝে মজার উত্তর (থ্রেডে সর্বোচ্চ ১টি, স্প্যাম/গালিতে নয়)।
